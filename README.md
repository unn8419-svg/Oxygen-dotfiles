# My First Dotfiles

Welcome! This is my first repository of dotfiles, specifically tailored for the **mangowc** compositor. I chose `mangowc` because it is simple, lightweight, and very resource-friendly.

![how it looks](/screenshots/20260826232702.png)
![how it looks2](/screenshots/20260826234201.png)

## 🛠️ Software Components

Here is the list of tools and versions these configurations were built and tested on:

* **Compositor:** `mangowc` (v0.16.1)
* **Status Bar:** `waybar` (v0.15.0)
* **Application Launcher:** `rofi` (v2.0.0)
* **Notification Center:** `swaync` (v0.12.6)
* **Terminal Emulator:** `kitty` (v0.48.2)
* **Text Editor:** `helix` (v25.07.1)
* **Shell:** `fish` (v4.8.1)
* **Prompt:** `starship` (v1.26.0)
* **System Info:** `fastfetch` (v2.67.1)
* **Audio Visualizer:** `cava` (v1.0.0)
* **Wallpapers:** `swaybg` (v1.2.2)

## 📦 Prerequisites

To ensure everything displays correctly, make sure you have the following fonts installed on your system:
* `JetBrainsMono`
* `JetBrainsMono Nerd Font` (for icons)
* Any standard `sans-serif` font

## 🚀 Installation

Getting started is simple. Just copy the contents of the `Configs` directory into your local configuration folder

*Note: It is highly recommended to back up your existing configurations before copying these files.*
